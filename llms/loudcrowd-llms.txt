## API Reference
- [Authentication](https://docs.loudcrowd.com/reference/authentication-1.md)
- [Rate limits and error handling](https://docs.loudcrowd.com/reference/rate-limits-and-handling-errors.md): Handle LoudCrowd API responses and retries safely.
- [List program orders](https://docs.loudcrowd.com/reference/list_program_orders.md): Retrieves orders attributed to members of a LoudCrowd program. Each result identifies the program member and includes attribution methods, financial values, and platform timestamps. Orders are returned in the order LoudCrowd received them, with the most recent first. Requires the **Read orders** and **Read programs** scopes.
- [Submit Order Event](https://docs.loudcrowd.com/reference/submit_order_event.md): Submit order data to LoudCrowd for attribution and commission calculation.
- [Submit Return Event](https://docs.loudcrowd.com/reference/submit_return_event.md): How to submit refunds/returns using the Events API.
